## 🚀 **Sobre o Projeto**

Este é meu currículo interativo no estilo **cyberpunk**, desenvolvido com **React** e publicado no **GitHub Pages**. O objetivo é apresentar minha trajetória profissional de forma criativa e imersiva, fugindo do formato tradicional de currículo.

🔗 **Acesse online:** [https://tadashijr.github.io/tadashi-cyber-cv/](https://tadashijr.github.io/tadashi-cyber-cv/)

---

## 🎯 **Funcionalidades**

| Feature | Descrição |
|---------|-----------|
| ⚡ **Header Animado** | Título com efeito glitch e status em tempo real |
| 💻 **Terminal Interativo** | Simula um console com atualizações automáticas |
| 🧠 **Skill Tree** | Habilidades profissionais com barras de progresso |
| 🎯 **Missões** | Experiências profissionais no formato de quests |
| 🏆 **Conquistas** | Badges com raridades (Lendário, Épico, Raro) |
| 🔓 **Hack the System** | Botão secreto que revela conteúdo adicional |
| 📡 **Conexões** | Links para LinkedIn, GitHub e email |
